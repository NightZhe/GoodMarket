不要手改兩個產物；改來源檔後跑 `node --experimental-strip-types scripts/gen-tw-districts.mts`，
檢查用 `--check`，測試在 `src/data/tw-districts.test.ts`。

## 授權
「中華郵政股份有限公司『3+3郵遞區號』公開授權聲明」（官方 PDF，109/10/22；小b 於 2026-10-18 讀過內文）要點：
無償、非專屬授權，不限地域、時間與次數，可重製並「於各種介面公開呈現 3+3 郵遞區號」；
不得違反中華郵政相關軟體使用條款與各項法律，不得侵害中華郵政或第三人權益。
本專案只使用其中的**前 3 碼**，並放進公開 repo 與網頁；落在授權範圍內。
判斷的邊界（請使用者知悉）：聲明的文字是針對「3+3郵遞區號資料檔案」，前 3 碼檔案是同一個下載專區公開提供的另一份檔案，沒有另外的授權條款；
聲明沒有要求標示出處，本檔仍保留出處供查核。另有一份「本公司3+3郵遞區號系統使用規範說明事項」（115/04/14）只談**6 碼資料檔**的申請與每季更新，不適用於本專案使用的 3 碼檔。
